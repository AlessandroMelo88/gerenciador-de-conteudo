# Faixas completas

As faixas de áudio ficam diretamente nesta pasta. Para associar uma letra,
adicione um arquivo de texto com o mesmo nome-base da faixa, por exemplo:

```text
Soberania_Total.wav
Soberania_Total.txt
```

O material copiado de `Producao_Musical/02_Faixas` contém as faixas completas
em WAV, mas não contém as letras. O pipeline não depende das letras para inserir
o trecho musical no encerramento.
