# Plan 05-04: Publisher and raw cleanup

## Wave

Wave 2 - Depends on 05-02 and 05-03.

## Goal

Publicar clips `pending`, persistir resultado no banco, respeitar quota/horario e limpar videos brutos com seguranca.

## Requirements

- PUB-01
- PUB-02
- PUB-03
- PUB-04

## Files

- `clip-processor/src/publisher.py`
- `clip-processor/tests/test_publisher.py`

## Tasks

1. Select publishable clips:
   - `generated_clips.status = 'pending'`
   - `clip_path IS NOT NULL`
   - `title IS NOT NULL`
2. Before each upload, call `QuotaManager.can_upload(now=...)`.
3. If blocked by quota/window, leave clip as `pending`.
4. Set clip status to `publishing` before calling uploader.
5. On upload success:
   - set `generated_clips.status = 'published'`;
   - set `youtube_video_id`;
   - set `published_at = UTC_TIMESTAMP()`;
   - clear `upload_error`;
   - call `QuotaManager.record_upload()`.
6. On upload failure:
   - set `generated_clips.status = 'failed'`;
   - set `upload_error`.
7. Update `source_videos.status` to `published` only when all clips for the source video are terminal and at least one was published.
8. Delete `source_videos.local_path` only under the same safe condition.

## Acceptance

- Successful upload transitions `pending -> publishing -> published`.
- Failed upload records error and does not increment quota.
- Quota/window block leaves status `pending`.
- Raw source file remains when another clip from same source is still pending/cutting/publishing.
- Raw source file is removed after all clips are terminal and one was published.
