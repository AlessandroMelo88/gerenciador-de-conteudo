## Tasks

1. Add idempotent migration:
   - Extend `generated_clips.status` to include `publishing`.
   - Add `published_at TIMESTAMP NULL`.
   - Add `scheduled_for TIMESTAMP NULL`.
   - Add `upload_error TEXT NULL`.
   - Use `INFORMATION_SCHEMA` + prepared statements for new columns.
2. Add module skeletons with explicit interfaces:
   - `QuotaManager.can_upload(now=None)`.
   - `QuotaManager.record_upload(now=None)`.
   - `YouTubeUploader.upload_clip(clip)`.
   - `publish_pending_clips(conn, redis_client, uploader=None, now=None)`.
   - `run_pipeline_once(db_conn=None, redis_client=None)`.
3. Add RED tests that express expected behavior without making network calls.
4. Run the targeted pytest files and confirm failures are expected missing behavior, not import/path failures.

## Acceptance

- Tests collect successfully.
- Tests fail because behavior is unimplemented.
- Migration is syntactically consistent with the existing Phase 3 migration pattern.
