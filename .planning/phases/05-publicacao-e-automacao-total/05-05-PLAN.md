# Plan 05-05: Pipeline runner and daemon integration

## Wave

Wave 3 - Integration.

## Goal

Extrair uma execucao completa do pipeline para um runner reutilizavel e integrar a publicacao ao ciclo ja existente do daemon.

## Requirements

- ORC-01
- PUB-01
- PUB-02
- PUB-03
- PUB-04

## Files

- `clip-processor/src/pipeline_runner.py`
- `clip-processor/src/main.py`
- `clip-processor/src/rss_poller.py`
- `clip-processor/tests/test_pipeline_runner.py`

## Tasks

1. Implement `run_pipeline_once(db_conn=None, redis_client=None)`.
2. Move responsibility for one full cycle to the runner:
   - RSS poll / download / AI / video processing through existing `poll_all_channels`;
   - publish pending clips after clip processing.
3. Update `main.py` so boot execution and APScheduler job call the runner.
4. Keep dependency injection for tests.
5. Ensure failures in publication do not stop future scheduler cycles.

## Acceptance

- Scheduler still has `coalesce=True` and `max_instances=1`.
- Importing `main.py` does not start the scheduler.
- Runner invokes publisher after existing clip processing.
- Test verifies ordering and injected db/redis reuse.
