# Plan 05-02: Quota and schedule guard

## Wave

Wave 1 - Parallelizable.

## Goal

Implementar o controle que impede uploads fora da janela 19h-22h e impede exceder a quota diaria.

## Requirements

- PUB-02
- PUB-03

## Files

- `clip-processor/src/quota_manager.py`
- `clip-processor/tests/test_quota_manager.py`

## Tasks

1. Implement `QuotaManager`.
2. Use timezone `America/Sao_Paulo` via `zoneinfo.ZoneInfo`.
3. Read `MAX_UPLOADS_PER_DAY` from env and clamp to `<= 6`.
4. Default to `2` uploads/day for first production usage.
5. Store count in Redis key `youtube_uploads:{YYYY-MM-DD}`.
6. Set key TTL until next local midnight after first increment.
7. Return false outside `19:00 <= hour < 22:00`.

## Acceptance

- Unit tests pass for:
  - inside window and below quota;
  - outside window;
  - quota reached;
  - env value above 6 is clamped;
  - TTL points to next Sao_Paulo midnight.
