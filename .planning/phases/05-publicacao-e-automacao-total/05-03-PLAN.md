# Plan 05-03: YouTube uploader

## Wave

Wave 1 - Parallelizable.

## Goal

Implementar upload de clip e thumbnail via YouTube Data API v3 usando o token OAuth existente.

## Requirements

- PUB-01

## Files

- `clip-processor/src/uploader.py`
- `clip-processor/tests/test_uploader.py`
- `clip-processor/requirements.txt`

## Tasks

1. Add required Google client dependencies if missing:
   - `google-api-python-client`
   - `google-auth`
   - `google-auth-oauthlib`
2. Implement credential loading from `YOUTUBE_TOKEN_FILE`, default `/app/token.json`.
3. Refresh expired credentials when `refresh_token` exists.
4. Build a YouTube service with injectable factory for tests.
5. Implement video upload with:
   - `snippet.title`
   - `snippet.description`
   - `snippet.tags`
   - `snippet.categoryId = '17'` for sports
   - `status.privacyStatus = YOUTUBE_PRIVACY_STATUS` default `private`
6. Implement thumbnail upload when `thumbnail_path` exists.
7. Return the published YouTube video id.

## Acceptance

- Tests pass with mocked YouTube service.
- Missing clip file raises a clear exception before API call.
- Missing token file raises a clear exception.
- Thumbnail failure is surfaced to caller; publisher decides status.

## Verification

```bash
pytest clip-processor/tests/test_uploader.py
```
