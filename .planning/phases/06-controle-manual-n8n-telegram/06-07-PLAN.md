   - **MySQL "Query Pending"**:
     ```sql
     SELECT id, title, ROUND(TIMESTAMPDIFF(SECOND, start_time, end_time)) AS duration_s
     FROM generated_clips
     WHERE status='pending'
     ORDER BY created_at ASC
     LIMIT 10
     ```
     (Se os campos `start_time`/`end_time` não existirem no schema, usar `duration_seconds` ou fallback `'?'`. Verificar schema antes de finalizar.)

   - **MySQL "Aprovar"** (executeQuery):
     ```sql
     UPDATE generated_clips SET status='approved' WHERE id={{ Number($('Parse Comando').first().json.arg) }} AND status='pending';
     SELECT ROW_COUNT() AS affected;
     ```
     **CRITICAL: validar input como inteiro** — o JS `Number(...)` retorna NaN se arg não numérico, que vira "NaN" na query e quebra.
