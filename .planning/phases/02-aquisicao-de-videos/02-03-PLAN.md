  <files>canaldecortes/clip-processor/src/downloader.py</files>
  <behavior>
    - download_video(video_id, output_path=None) → bool:
      1. Se output_path é None, usar f'/app/videos/{video_id}.mp4'
      2. Verificar shutil.disk_usage(VIDEOS_DIR).free >= MIN_FREE_BYTES; se não, logar e return False
      3. url = f'https://www.youtube.com/watch?v={video_id}'
      4. ydl_opts com format 'bestvideo[height<=720]+bestaudio/best', merge_output_format 'mp4', outtmpl output_path, quiet True
      5. Loop for attempt in range(1, 4):
         a. Tentar yt_dlp.YoutubeDL(ydl_opts).__enter__().download([url])
         b. Em sucesso: return True
         c. Em DownloadError: checar se msg contém PERMANENT_ERRORS; se sim, cleanup e return False
         d. Se não permanente: cleanup .part, logar tentativa, time.sleep(60) se attempt < 3
      6. Após 3 falhas: return False
    - _cleanup_partial(path): deleta path + '.part' se existirem com os.path.exists + os.remove
    - test_download_success passa: YoutubeDL mockado sem exceção → returns True
    - test_disk_space_guard passa: shutil mockado com free=1GB → returns False, yt-dlp não chamado

    - test_permanent_error_no_retry passa: DownloadError('private') → 1 tentativa, return False
    - test_retry_transient_error passa: DownloadError('connection') → 3 tentativas antes de return False
