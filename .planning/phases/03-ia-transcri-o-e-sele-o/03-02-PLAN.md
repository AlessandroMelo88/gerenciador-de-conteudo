GREEN (implementar):

1. `transcribe_video(video_id, video_path, groq_client=None, db_conn=None) -> dict | None`
   - Se groq_client é None → instanciar `from groq import Groq; groq_client = Groq()`
   - Verificar tamanho do arquivo: `os.path.getsize(video_path) > 24_000_000`
     - Se sim → chamar `_prepare_audio(video_path)` para extrair MP3 via ffmpeg
     - Se não → usar video_path diretamente
   - Chamar `groq_client.audio.transcriptions.create(file=f, model='whisper-large-v3-turbo', response_format='verbose_json', timestamp_granularities=['segment'], language='pt', temperature=0.0)`
   - Serializar segments: `[{'start': seg.start, 'end': seg.end, 'text': seg.text} for seg in result.segments]`
   - Retornar `{'video_id': video_id, 'text': result.text, 'segments': segments}`
   - Em qualquer Exception: logar com _log() e retornar None
   - Limpar arquivo de áudio temporário se foi criado

2. `save_transcript(conn, video_id, transcript) -> str`
   - Montar caminho: `os.path.join(VIDEOS_DIR, f'{video_id}_transcript.json')`
   - Salvar com `json.dump(transcript, f, ensure_ascii=False, indent=2)`
   - Executar: `UPDATE source_videos SET transcript_path=%s WHERE youtube_video_id=%s`
   - Fazer `conn.commit()`
   - Retornar caminho do arquivo JSON

3. `_prepare_audio(video_path) -> tuple[str, bool]`
   - audio_path = video_path.replace('.mp4', '_audio.mp3')
   - Chamar subprocess.run(['ffmpeg', '-i', video_path, '-vn', '-ar', '16000', '-ac', '1', '-b:a', '32k', audio_path, '-y'], check=True, capture_output=True)
   - Retornar (audio_path, True) — o True indica que deve ser deletado após uso
